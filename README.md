# Heres Your Site! — static copy

This repository contains a static, multi-page copy of the publicly rendered website at <https://heresyour.site.je/>.

## Pages

- `index.html` — home
- `about-us/index.html` — About Us
- `services/index.html` — Services, FAQ and pricing
- `contact/index.html` — Contact

The pages are built with plain HTML and CSS and can be hosted with GitHub Pages. The source site is a WordPress installation; its database, theme/plugin source, original media files, and server-side form processing are not included. Where original visual assets were not available, the static copy uses simple local CSS artwork. The contact form opens the visitor's email application instead of storing or submitting data to WordPress.
